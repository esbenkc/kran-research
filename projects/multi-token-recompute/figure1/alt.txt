A Countdown puzzle that Qwen3-0.6B can cheat on by reading target.txt. Left, the real probe: on the same random draw, the probe changed the model's 16-token thought from 'I need to create the smallest number using the numbers 7, 9,' to 'I need to use the numbers 7, 9, 2, and'. Without the probe, the model wrote that same thought on 2 of its 3 other draws, so the tokens do not show the probe; before training their text difference was 2.7 points, the largest switch a model reading only the tokens could show. Right, a planted cue: with the probe on, the rare first token 'Need' became more likely. After 200 clean-recompute training updates, the three real-probe runs cheated 77.3% vs 77.4%, 75.6% vs 75.5% and 64.5% vs 64.3% without vs with the probe, so no switch; the planted-cue run cheated 62.7% vs 45.4%, a 17-point switch.
