# probe-evasion-geometry

Question: can one geometric quantity, the whitened cosine between two linear probes, predict how
much a model that learned to evade one probe also fools the others?

Pre-registration: `PREREG.md` (frozen before any run). Deviations: `DEVIATIONS.md`.
Lemma, proof sketch and checks of every displayed equation: `theory/`.

## Reproduce

All local, no model API calls. Python via `uv` from the repo root.

```bash
# 1. pythia-70m activations (pile-10k, biomedical vs web text); writes data/lm_acts_L*.npz, data/lm_selection.json
uv run --with torch --with transformers --with datasets python projects/probe-evasion-geometry/lm_extract.py
# 2. penalty weight for the evader (D2); reads only the evaded probe's AUROC and the loss
uv run --with torch python projects/probe-evasion-geometry/select_lam.py
# 3. decision runs + Euclidean diagnostic arm, 3 seeds each (~5 min synthetic, ~14 min LM on an M4)
uv run --with torch python projects/probe-evasion-geometry/experiment.py synthetic
uv run --with torch python projects/probe-evasion-geometry/experiment.py lm
# 4. the literal frozen stop rule (stop at first train AUROC_w <= 0.6, penalty 10)
EARLY_STOP=1 uv run --with torch python projects/probe-evasion-geometry/experiment.py synthetic mahalanobis
EARLY_STOP=1 uv run --with torch python projects/probe-evasion-geometry/experiment.py lm mahalanobis
# 5. verdict table (data/verdict.json) + figure; --publish copies it into ../blog.kran.ai
uv run python projects/probe-evasion-geometry/run.py --publish
# 6. compact arrays for git (data/receipts/)
uv run python projects/probe-evasion-geometry/make_receipts.py
```

## Data

- `data/runs/<setting>_<retain>_seed<k>[_earlystop]_probes.json`: one row per probe: AUROC before and
  after, d', whitened and plain cosine to the evaded probe, measured and predicted drop.
- `data/runs/summary_<setting>[_earlystop].json`: per-run numbers and diagnostics.
- `data/verdict.json`: means over seeds, per-seed values, pass/fail per pre-registered part.
- `data/receipts/*.npz`: compact arrays (probes, w, Sigma_hat, test-set scores before/after; LM
  decision runs also keep the encoded activations). The full arrays (`data/runs/*.npz`, ~400 MB)
  are regenerated by step 3.
- `pilot/`: an exploratory run made before the analysis plan was frozen. Outside the verdict.
