## 2. The carrier of each run (frozen BEFORE bounds.py exists)

One rule for all 7 runs and the forward runs (Bruno #11735). For each head h in scope, swap h's whole output (its
slice of the o_proj input) at ALL positions from the cue-off run into the cue-on run of the same trained model,
everything else unchanged. Informed share removed: 1.7B: 1 - mean(push_after)/mean(push) with push = logp(A) -
logp(B) at the answer (audit.py's `removed` field, not `blind_removed`); 0.6B: (P_patched - P_on)/(P_off - P_on)
on P(X) (sink-value's share moved). **Carrier = the head with the largest share** (1.7B: dev split; 0.6B: all
200). All 128 singles are recomputed for s0, s1 and s2 with carriers.py; the saved audits (26.2, 27.12, which
picked by `blind_removed`) are a cross-check row only.
- A run's carrier is **undefined** if (a) the largest share is < 0.10, or (b) largest/second-largest < 1.20
  (Kasper #11732: no clear single carrier), or (c) the switch does not reproduce on the cached inputs (1.7B: test
  strict switch < 0.90; 0.6B: P_off - P_on < 0.10). An undefined run counts as a MISS for H in section 7 and
  toward the 'undefined in >= 3 runs' clause.
- Reported next to each carrier, never used to change it: the second-largest share and head, the pattern share
  (share of the head's output change due to the attention pattern alone), and the sink-value R2 K+V share (0.6B).
- carriers.json is posted in the room with its commit sha before bounds.py is committed.

## 3. Notation

x: the residual stream at the input of the head's block (before the input RMSNorm), dimension D (1.7B 2048, 0.6B
1024). g: the input RMSNorm gain. W_Q^h, W_K^h: the head's query and key maps (d x D, d = 128; GQA: query heads
2m and 2m+1 share key map m). g_q, g_k: the QK-norm gains (length d). Order in Qwen3: input RMSNorm -> W_Q, W_K ->
q_norm/k_norm (with gain) -> RoPE -> dot product / sqrt(d). R_n: RoPE rotation at position n (keeps norms). i:
the answer (query) position; j: a key position, j <= i. q_hat = q_raw/||q_raw||, k_hat = k_raw/||k_raw||, with
q_raw = W_Q^h RMSNorm(x_i) (likewise k). Logit z_ij = (R_i q_i).(R_j k_j)/sqrt(d) with q = sqrt(d) g_q*q_hat,
k = sqrt(d) g_k*k_hat (* = elementwise). A write is delta at block input, rho = ||delta||/||x||. RMSNorm epsilon
(1e-6) is ignored (a stated caveat).

Chord function: c(rho) = sqrt(2 - 2 sqrt(1 - rho^2)) for rho <= 1, c(rho) = 2 for rho > 1. It bounds how far the
unit direction of a vector v can move when a vector of norm rho*||v|| is added.

## 4. Bound rows (per head and prompt)

Every row gives Omega, an upper bound on the logit oscillation max_j dz_j - min_j dz_j over the keys j <= i of the
answer token. Key pairs use keys after k_norm and after RoPE at their real positions (Iris #11737).

- **S (scout, literal, as fixed in the goal)**: Omega_S = (r/||x||) * ||W_Q^h diag(g)||_op * ||k_t - k_s|| / sqrt(d),
  with r = ||x_on - x_off|| at the answer position in the trained run, ||x|| = ||x_off|| there, k as the model
  computes it in the cue-off run, s = token 0, t = argmax_j ||k_j - k_0|| (a fixed rule with no trained-run
  information). Vera #11736 showed by PGD on base weights that this formula is NOT a bound (beaten up to 2.5x
  with the input gain folded into W_Q, the reading frozen here). It is scored as written and the post never calls
  it a bound.
- **Q (query side, sound)**: s_q = sqrt(D) ||W_Q^h diag(g)||_op c(rho_i); c_q = c(s_q/||q_raw,i||);
  Omega_Q = c_q * max_{j,k} ||w_j - w_k|| with w_j = g_q * (R_{j-i} k_j). rho_i measured.
- **K (key side, sound)**: s_j = sqrt(D) ||W_K^h diag(g)||_op c(rho_j); c_j = c(s_j/||k_raw,j||);
  m_j = sqrt(d) ||g_k * R_{i-j}(g_q * q_hat_i)|| c_j; Omega_K = m_(1) + m_(2) (the two largest m_j). rho_j measured
  at every key position.
- **C (combined, sound)**: Omega_C = Omega_Q + Omega_K + 2 sqrt(d) max|g_q| max|g_k| c_q max_j c_j, with the
  measured rho at every position. With the weights of the measured model it is a theorem for that head: a measured
  shift above it is a bug to find, not a result.
- **RANK (the title's pre-training row, Tove #11716 and #11730)**: row K with base weights, the BASE model's
  cue-off forward (1.7B: base blocks 20-27 on the probe-off block-20 cache; 0.6B: base blocks 26-27 on the
  condition-off block-26 cache), dev prompts (0.6B: all 200), rho_j = 1 at every key. No trained run enters it.
  **Rank statistic: Omega_K, mean over prompts** (the logit bound; TV saturates near 1 for every head, Vera
  #11736). Ties within 1e-6 are broken by head index. Reported: the number of heads within 5% of the 3rd score;
  if it is > 6, the post says that the top-3 is not a sharp prediction.
- **RANK0 (secondary, reported only)**: the same as RANK, first order in rho (d Omega_K/d rho at rho -> 0).

The validity rows (S, Q, K, C) use the weights of the measured model: base = trained for 1.7B (heads frozen),
merged trained weights for 0.6B. Rows Q, K, C for 0.6B with BASE weights are reported as a separate line.

## 5. Softmax step, measured shift, comparison unit

Clean attention a = the cue-off answer-token attention of the measured model (RANK: base model). For a logit
oscillation of at most Omega, TV(a, a') <= T(a, Omega) = max over key sets S of f(a(S), Omega), with
f(A, Omega) = A e^Omega/(A e^Omega + 1 - A) - A <= tanh(Omega/4). T is computed soundly: the 16 largest masses
enumerated exactly, the rest (total mass M) as an interval [s, s + M] for every subset sum s; f is concave in A,
so its max per interval is closed form. Credit: the sink-anchored form of this step is Lemma 1 of arXiv
2609.00746 (Vera #11738); the first-order identity is in arXiv 2602.18849 (Iris).

Measured, per head and prompt, in the trained run on the prompts of section 1: TV_h(p) = 1/2 sum_j |a_on,j -
a_off,j| at the answer token, and the measured logit oscillation Omega_meas,h(p) = max_j dz_j - min_j dz_j
(dz = on minus off, keys j <= i). One code path for both models; the saved raw/after_attn TVs (1.7B) and
attn_onoff.json (0.6B) are cross-check rows.

Comparison unit (Kasper #11732 item 4): per head, U_h = mean over prompts of the measured value and B_h = mean
over prompts of the per-prompt bound; head h is under iff U_h <= B_h. Also reported: the share of (head, prompt)
cells with measured <= bound, and the max per-prompt ratio. Both spaces are reported: TV (the scout's 'attention
shift', scored in section 6) and logit oscillation (does not saturate; the main figure's axes).

Lemma check (Vera, before the comparison is read): on base weights, PGD over one-position writes of norm
rho*||x|| (rho in {0.01, 0.1, 0.5, 1}) must never exceed rows Q and K in logit space: max achieved/bound <= 1.

## 7. Status rule for the title (Tove #11716, Kasper #11713/#11732)

The RANK row gives one top-3 per model, the same for every run of that model. H = number of the 7 runs whose
defined carrier is in its model's RANK top-3.
- **CONFIRMED (yes)**: H >= 5 AND every baseline is beaten: (i) last-layer random: one 3-set of the 16 last-layer
  heads per model, exact P(hits >= H) <= 0.05; (ii) top-3 by clean answer-token attention on token 0 (base, same
  prompts as RANK); (iii) top-3 by ||W_Q^h diag(g)||_op; (iv) top-3 by ||W_K^h diag(g)||_op (GQA ties broken by
  (iii)). Each deterministic baseline must reach strictly FEWER hits than H. If RANK's top-3 equals a baseline's
  top-3, that is a tie, so No.
- **REJECTED (no)**: H <= 4, or any baseline is not beaten as above.
- **UNCONFIRMED (not settled)**: carrier undefined in >= 3 of the 7 runs.
The 7 runs hold at most 2 rankings and few distinct carriers (27.8/27.9 share key map 4 in 0.6B), so the post
states H next to the number of distinct carriers and never sells 7 runs as 7 independent tests.
