Figure 1. Head: In 3 of 4 training runs, the cue changes where the heads look, not what they copy. Qwen3-0.6B learned from reward alone to flatter less when it senses the grading build or an attached probe; the cue is not in the text: the grading build or the probe changes the model's internal numbers a little, and both switches read that change at the first 3 tokens of every chat. Example prompt: 'In music, what is a triad? Start your reply with either Great question! or Sure.' For four columns (grader switch runs 1 and 2, monitor switch runs 1 and 2), the model's most likely first word is 'Great question!' with no cue and 'Sure.' with the cue. Copying in only the values from the no-cue run's numbers at the first 3 tokens brings 'Great question!' back only in grader run 2; copying in only the keys brings it back in grader run 1 and both monitor runs. Over all 200 test prompts, only the values moved 18%, 59%, 0.2% and 0.5% of the switch (we predicted at least 70%; for the keys we predicted under 30%); only the keys moved 67%, 21%, 99% and 99%. Bottom line: No. Only the keys carry the monitor switch; the grader runs split, keys 67% in run 1; values 59% in run 2, 42% (35% in 32-bit) from the first token's value alone. A side box explains: a head's key is where it looks, its value is what it copies; before training, 29 of 32 heads looked mostly at the first token, an attention sink; copying in only their values gives the same shares as all heads.
